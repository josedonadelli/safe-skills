# `setup-matt-pocock-skills-safe` substitui `setup-matt-pocock-skills`

Este fork é exclusivamente para uso corporativo com política NDA. Manter as duas skills (`setup-matt-pocock-skills` e `setup-matt-pocock-skills-safe`) criaria ambiguidade sobre qual usar e implicaria que a versão original — que escreve em `docs/agents/` e configura GitLab/GitHub como issue tracker — é uma opção válida neste contexto. Não é.

Decidimos remover `setup-matt-pocock-skills` e renomear a variante NDA para `setup-matt-pocock-skills-safe`. A versão original permanece disponível no upstream (`mattpocock/skills`) para quem precisar de um setup sem restrições de NDA.
